정보통신설비 유지보수 관리 및 성능점검 계획 업로드 자동화 사진은 이 PC 밖으로 전송되지 않습니다
How to use · Guide

사용법 처음이어도 5분이면 끝나요

준비물 2가지
① 사진 넣기 전 워드 파일(.docx)
② 현장 사진(jpg·png, 폴더째 가능)
그림은 누르면 크게 볼 수 있어요. 키보드 ← →로 넘기고 Esc로 닫아요.

1워드 파일 넣기

파일 선택을 눌러 사진 넣기 전 워드를 고르세요. 파일을 칸 안으로 끌어다 놓아도 됩니다.

잘못 골랐으면 취소를 누르고 다시 고르면 돼요.

💡 예전에 이 사이트로 사진을 넣었던 워드를 다시 넣어도 괜찮아요. 들어 있던 사진·계통도는 자동으로 지우고 새로 넣습니다.

2현장 사진 넣기

  • 몇 장만 넣을 때: 사진 파일 줄의 파일 선택 → Ctrl을 누른 채 여러 장 클릭(전부는 Ctrl+A)
  • 폴더째 넣을 때: 사진 폴더 줄의 폴더 선택 → 폴더 고르기 → 브라우저가 "업로드할까요?" 물으면 업로드 (사진은 내 PC 밖으로 나가지 않아요)
  • 줄마다 취소가 따로 있어서 잘못 넣은 쪽만 지울 수 있어요.

3넣은 사진 확인하기

아래에 1, 2, 3… 번호가 붙은 사진이 나와요. 번호 순서 = 워드에 들어가는 순서(파일 이름 순, 보통 찍은 시간 순)입니다.

필요 없는 사진은 오른쪽 위 ×를 눌러 빼세요.

4자동 분류 시작

자동 분류 시작을 누르면 막대에 진행률(%)·속도·남은 시간이 나와요.

⏱ 처음 한 번만 분류 엔진을 받느라 1~2분 걸리고, 다음부터는 바로 시작돼요.

5결과 화면 보는 법

  • 왼쪽 = 완성될 워드 미리보기 (마우스로 끌거나 휠로 위아래 이동)
  • 오른쪽 = 1-1 케이블 ~ 1-10 통신 접지까지 항목별로 나뉜 사진
  • 빨간 테두리 사진은 자동 분류가 헷갈린 사진이에요. 꼭 눈으로 확인하세요.

6잘못 들어간 사진 옮기기

  • 방법 1: 사진 아래 선택 상자에서 맞는 항목 고르기
  • 방법 2: 사진을 끌어서 맞는 항목 칸에 놓기

옮기면 왼쪽 워드가 바로 바뀌고, 위에 ✓ 미리보기 최신이 나오면 반영 끝이에요.

↩ 빨간 사진을 옮겼다가 원래 칸으로 되돌리면 빨간 표시도 다시 생겨서, 확인할 사진을 놓치지 않아요.

7사진이 워드 어디에 들어갔는지 보기

오른쪽 사진을 한 번 누르면 왼쪽 워드가 그 사진 칸으로 이동하고 주황색으로 표시돼요. 반대로 왼쪽 워드의 사진을 누르면 오른쪽에서 그 사진을 찾아 줍니다.

8워드에 넣지 않을 사진

맨 아래 🚫 제외 칸으로 옮기면 그 사진은 워드에 들어가지 않아요. 잘못 옮겼으면 다시 원래 칸으로 옮기면 됩니다.

9워드 만들기

  • 지난 회차 계통도 넣기: 켜 두면 항목마다 계통도가 들어가요.
  • 사진을 칸에 꽉 채우기: 켜면 테두리에 빈틈없이 맞춰요(가장자리가 조금 잘림). 끄면 사진 전체가 보이게 넣어요.
  • 다 됐으면 ③ 워드 만들기를 누르세요.

10완성 확인

완성 파일을 다시 열어 항목마다 계통도 1개, 사진 수·순서가 화면과 같은지 자동으로 검사해요.

  • 초록색 "검사 통과"가 보이면 끝. 파일은 다운로드 폴더에 저장돼요.
  • 빨간색 문제가 보이면 파일을 내려받지 않아요. 그 화면을 캡처해서 담당자에게 알려 주세요.

?자주 묻는 질문

버튼이 눌리지 않아요

키보드 Ctrl+F5로 새로고침해 보세요. 화면 아래 "분류 기준: …" 문구가 보이면 정상이에요.

사진 순서를 바꾸고 싶어요

사진은 파일 이름 순서로 들어가요. 순서를 바꾸려면 파일 이름 앞에 01_, 02_처럼 번호를 붙인 뒤 다시 넣으세요.

사진 가장자리가 잘려요

"사진을 칸에 꽉 채우기"를 끄면 사진 전체가 보이게 들어가요(대신 칸에 여백이 생겨요).

미리보기 글씨 모양이 워드와 조금 달라요

미리보기는 빠르게 보여 주려고 간단히 그린 화면이에요. 실제 워드 파일은 원래 양식 그대로이고, 사진도 원래 화질로 들어갑니다.

현장 사진이 회사 밖으로 나가나요?

아니요. 사진 분류와 워드 만들기는 모두 지금 보고 있는 브라우저 안에서 처리되고, 어디에도 전송되지 않아요.

분류가 자꾸 틀려요 / 계통도가 바뀌었어요

분류 기준은 지난 회차(2026-07-30) 완성본이에요. 새 회차 완성본을 담당자에게 주면 기준을 새로 바꿔 더 정확해집니다.
